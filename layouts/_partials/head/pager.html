{{- /* Returns the page's paginator, or false when the page is not paginated. Single source of the pagination decision: taxonomy terms and the sections listed in `site.MainSections` (Hugo defaults it to the section with the most pages). `list.html` and `term.html` range this result, and the head partials use it for canonical and rel=prev/next. `archives` and `search` have their own list templates that never range a paginator, so they are excluded even when they are a main section. Calling `.Paginator` anywhere else makes Hugo render duplicate `/page/N/` pages, so templates must ask this partial instead of calling it directly. */ -}} {{- $pager := false -}} {{- $own := slice "archives" "search" -}} {{- if or (eq .Kind "term") (and (eq .Kind "section") (in site.MainSections .Section) (not (in $own .Section))) -}} {{- $pager = .Paginator -}} {{- end -}} {{- return $pager -}}
